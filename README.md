# MonkeyMind GMB Scraper

Google Maps Chrome Extension + Next.js/Vercel dashboard + Supabase database starter.

## Architecture
Google Maps -> Chrome Extension -> Supabase -> Next.js/Vercel Dashboard

## Extension testing
Open `chrome://extensions/`, enable Developer mode, choose **Load unpacked**, and select `extension/`.
